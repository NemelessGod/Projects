# Spin Kingdom — original design

Working name is replaceable in `client/project.godot`, export preset and remote brand config. Setting a new Android application ID after release has store consequences.

Players are navigators restoring floating islands in a sea of stars. Sparks power an ancient three-reel mechanism. Coins illuminate five landmarks; rebuilding every landmark opens the next island. Palette: midnight blue, warm gold, mint and lavender; vector symbols and sky islands are original placeholders. No imported franchise art, text or sounds.

Short goal: spend a few sparks, afford the next upgrade. Medium goal: illuminate all five landmarks. Long goal: unlock worlds and later collections/events. Target session 2–10 minutes; no cash-out or wager currency. Premium currency exists as a reserved wallet field with no purchasing functionality.

Implemented worlds: Starhaven / Звёздная пристань and Cloudforge / Кузница облаков. Each has five landmarks and three upgrade levels. Finishing the last world shows campaign completion instead of endlessly awarding completion rewards.

Milestone 1 symbols: coin, bag, energy, star, crown/jackpot. Every reel pays configured rewards; three matching symbols multiply coin rewards. Attack/raid/shield/chest symbols must only enter live weights once their server implementations exist.

Tutorial states: first spin -> first upgrade -> done. Persisted locally, never authorizes rewards. Navigation: island, slot, profile. Other main-menu entries explicitly describe their planned status rather than pretending to work.
